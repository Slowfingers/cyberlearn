# Проверка 5 класса — 5 октября 2026

Проверены все 70 уроков: 37 тестов, 25 интерактивных тренажёров, 6 маршрутов с кодом, HTML и терминал. ID уроков и сохранённый прогресс сохраняются.

## Повторное открытие и дубликаты

- Каталог удаляет повторные ID из серверного списка; встроенный урок имеет приоритет над его старой копией. Авторские задания с отдельными ID остаются.
- Подтверждённый сервером результат не отменяется запоздавшим обновлением списка.
- «Далее» пропускает пройденные уроки, возвращается к ранним пропускам и завершает курс, когда пропусков нет.
- Завершённый курс не запускает первый урок автоматически. Для явно выбранного повторения показывается статус «Урок уже пройден».
- Кабинет перемонтируется при смене ученика; чужой прогресс не переносится. Сервер продолжает проверять повторное начисление наград.

## Содержание и тренажёры

- g5_l5: четыре схемы AND, OR, XOR, NAND вместо одного AND; объяснение и вопрос соответствуют сравнению правил.
- g5_l50: отдельная цель — выключенный выход XOR, вместо точного повтора первого XOR.
- Схемы проверяются кнопкой. Цель, совпадающая с начальным состоянием, теперь достижима без искусственного переключения входов.
- g5_l40: отдельная сеть с перегруженным узлом и ограничением 35 мс. Допустим A → C → E → F, 29 мс. Из сообщений об ошибках убрана подсказка конкретного роутера.
- g5_l30: авторское письмо и три связанные угрозы вместо чужого банковского сценария и лишнего вложения.
- g5_l43: четыре дела о проверке новостей вместо сценариев травли. Различаем непроверенное сообщение и подтверждённое, а не объявляем любую подозрительную новость доказанным фейком.
- g5_l62: артефакты изображения — повод проверить источник, а не доказательство генерации. Голос не подтверждает личность отправителя.
- g5_l31: убрана спорная классификация помидора и подпись с готовым ответом.
- g5_l32: примеры обоих классов в разных условиях и обязательный вопрос о роли фона.
- g5_l60: раздельные учебные и новые проверочные карточки, затем обязательный вопрос. Завершение только после всех этапов. Интерфейс честно описывает подготовку разметки, а не утверждает, что обучил настоящую модель.
- g5_l57: добавлено граничное значение 60; названия строк соответствуют баллам команд.
- Уточнены вопросы о цифровых копиях, обезличивании и теме письма; убрана гарантия 60 FPS от пула объектов.
- Различные уроки получили названия по своей теме. Названия областей конструктора подходят игровому экрану, истории и школьному порталу.
- Ханойская башня: видимые правила, доступные кнопки опор, отмена отложенного завершения при сбросе или уходе.
- В примере цикла используется доступная команда движения соответствующего урока.

## Проверка

- 70 уникальных ID, названий и практических сценариев, правильные ответы сохраняются при перемешивании теста.
- Все 25 интерактивных заданий пройдены через браузер до вызова завершения. Отдельно проверены неправильный ответ в расследовании и отсутствие раннего завершения задания по ИИ.
- Через curriculum-audit.html выполнены 103 проверки программ всех курсов с ожидаемым результатом, в том числе все 8 программных заданий 5 класса.
- Реальный StudentDashboard проверен с изолированной API-фикстурой: 68 → 69 уроков; затем старый ответ с 68; результат остался завершённым. «Далее» пропустила выполненные уроки, второй ответ довёл курс до 70/70. Повторное открытие показало завершённый курс, явный выбор урока — статус повторения. Старая копия урока в серверном каталоге не появилась второй строкой.
- На фактической ширине 390 px проверены объяснение, пример и вопрос каждого из 70 уроков (210 состояний), а также все 25 интерактивных экранов. Горизонтального переполнения страницы и перекрытия условия практикой не обнаружено. На desktop дополнительно проверены экраны всех 70 уроков.
- Общая схема AND 4 класса: неверная конфигурация не завершает урок; правильная после проверки завершает.
- Прошли npm run check, npx tsc --noEmit -p ., npm run validate:curriculum, npx tsx scripts/cosmetics.check.ts и npm run build.

Проверки кабинета и тренажёров изолированы от данных учеников. Запись прогресса реального ученика в production не выполнялась. Проверочные HTML-страницы доступны только локальному Vite и не входят в production-сборку.
