# Arduino C++ в мастерской умного города

23 октября 2026. В обеих миссиях добавлено реальное преобразование C++ в HEX и исполнение инструкций ATmega328P через AVR8js. Учебный интерпретатор первого этапа сохранён отдельным режимом. На localhost по умолчанию выбран C++; на опубликованном сайте по умолчанию остаётся учебный режим до подключения отдельного сервиса компиляции.

## Локальный запуск

1. Запустить Docker Desktop / Docker Engine.
2. Один раз выполнить `npm run setup:arduino-cpp` (образ `cyberlearn-avr:1`). В текущем рабочем окружении уже установлен.
3. `npm run dev` и курс «Умный город: мастерская Arduino».
4. В блоке программы выбрать «Arduino C++ · настоящая прошивка».

Vite/preview регистрируют `/api/arduino/compile`. Эндпоинт доступен только для loopback-соединения, с localhost Host, проверяет Origin, принимает POST с `{code}`. Cloud/Vercel-функция этот сервис не публикует: для размещённой платформы нужен отдельный изолированный компилятор с авторизацией/лимитами. Не публиковать локальный middleware как общий сервис.

## Компилятор

Образ собирает Arduino AVR Core, Servo 1.2.2 и подготовленный драйвер HC-SR04. `avr-g++` компилирует исходник GNU C++11, `avr-objcopy` выдаёт Intel HEX; успешная прошивка соответствует полученному коду. Никаких подстановок заранее готовой программы или распознавания по словам. Доступны функции, массивы, for/while, глобальное состояние, Arduino API, Servo и Serial. Сторонние библиотеки автоматически не устанавливаются. Как в обычном C++, свои функции нужно объявлять до использования или добавлять прототипы.

Префикс включает Arduino.h и объявляет readDistance(); `#line` сохраняет номера строк редактора в диагностике GCC. readDistance — драйвер на TRIG D9 / ECHO D10, результат округляется до сантиметра для устойчивой границы 40 см. Сборка Debian AVR GCC использует DECIMAL_DIG=9 для совместимости с 32-битными float/double Arduino Core.

Каждая компиляция создаёт отдельный непривилегированный контейнер: без сети и host mounts, read-only root, без capabilities, no-new-privileges, tmpfs для исходника/объектов, лимиты CPU/RAM/PID и 25 секунд. Программа передаётся stdin, не подставляется в shell-команду. Объём исходника ограничен 32 КБ. Не более двух параллельных сборок. Кеш ограничен 32 прошивками; ключ включает исходник и ID образа, поэтому обновление образа инвалидирует кеш. Контейнер удаляется после завершения.

## Исполнение и связь с 3D

Эмулятор работает в отдельном Web Worker: ATmega328P/16 МГц, 32 КБ flash, 2 КБ SRAM, порты B/C/D, Timer0/1/2, ADC и UART. HEX проверяется по контрольным суммам и границам flash. Состояние продолжается между итерациями loop, без повтора заранее рассчитанных двух циклов.

- Светофор читает реальные состояния D8/D9/D10 из эмулятора.
- HC-SR04 отвечает на импульс TRIG D9, формируя ECHO D10 заданной длительности. Перемещение машины меняет расстояние без перезагрузки программы.
- Угол серво получается из длительности импульсов на D6, создаваемых библиотекой Servo.
- Serial.println отображается в мониторе порта, вывод ограничен последними 4096 символами.

Поддержка конкретных внешних устройств ограничена этими миссиями: эмулятор не моделирует произвольные аналоговые схемы или все периферийные библиотеки. Загрузка на физическую плату пока не подключена.

## Проверка миссий

Проверка исполняет ту же скомпилированную прошивку в отдельном состоянии: светофор — 13 секунд виртуального времени; шлагбаум — 15/39/40/65/120 см по 350 мс. У светофора проверяются наблюдаемые состояния, порядок и длительности (микросекундные промежутки переключения исключаются); у серво допускается погрешность декодирования импульса 1°. Это ограниченные сценарные тесты, не формальное доказательство поведения любой программы.

Редактирование/выход прекращают Worker, отменяют ожидание и исключают награду от устаревшей проверки. Ошибка компиляции не включает учебный режим автоматически. Если компилятор недоступен, ученик видит ошибку и может явно выбрать учебный режим.

## Проверки и источники

- `npm run check:arduino-cpp`: настоящая GCC-компиляция, GPIO/таймеры, пять расстояний, функции/массивы/for, UART, состояние дольше двух циклов, ошибки и изоляция host filesystem; браузер обеих миссий на 1440/390 px с фикстурными учениками, отмена проверки, Serial, сохранение и повтор без наград.
- `npm run check:smart-city`: прежний учебный режим, не требует Docker.
- TypeScript, production-сборка и учебный каталог.
