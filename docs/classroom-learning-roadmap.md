# Путь развития классного урока CyberLearn

## Принципы

Приоритет — 3–4 классы. Работаем небольшими проверяемыми этапами: сначала один экран, затем один полный урок и только после испытания распространяем решения на другие темы. Курсы 5–8 классов и лаборатории сохраняют текущий режим. Индивидуальное прохождение, прогресс, инвентарь и награды сохраняются. Коммиты и публикация — только по отдельному запросу.

## 1. Визуальный пилот: первый урок 3 класса

Обновить экран объяснения «Что подсказывает имя файла»: светлая учебная поверхность, яркий пример, крупная типографика, мягкие скругления, минимум рамок и сохранение игрового персонажа. Сохранить четыре этапа, три учебных примера, исправление ошибок и переход к самостоятельному заданию. Проверить на компьютере и телефоне, включая работу с клавиатурой.

Результат этапа — работающий экран, который можно оценить и скорректировать до изменения остальных уроков. Это ещё не совместная презентация.

## 2. Пилотный сценарий совместного урока

Подготовить для одной темы 3 класса (предлагаем «Алгоритмы: порядок действий») сценарий: 5–7 слайдов с одной мыслью на каждом, заметки учителю и вопросы для обсуждения, 2–3 задания и 4–5 вопросов для закрепления. Визуально показать детский слайд, пульт учителя и задание. Уточнить содержание по результатам просмотра пользователем.

## 3. Базовый урок под управлением учителя

Выбор класса и запуск занятия; управление этапом и слайдом; одинаковый слайд у учеников; отдельные заметки только для учителя; состояние подключения и восстановление при потере связи. Кнопка «Внимание на учителя» затемняет экраны и возвращает к прежнему состоянию. Выбор и повтор слайда не стирают ответы и черновики. Учитель управляет переходами вручную.

## 4. Задания и готовность класса

Адаптировать сначала пилотные задания, затем остальные распространённые тренажёры 3–4 классов. Показывать один основной шаг и действие, подсказки открывать по запросу. Учителю доступны статусы: работает, нужна помощь, готов, нет связи. Начало общего этапа не удаляет незавершённую работу.

## 5. Общая викторина

Выбор одного ответа, понятные цвета плюс буквы и символы, управление учителем, отключаемый таймер, объяснение после вопроса, возвращение после разрыва связи. Сервер принимает один ответ на вопрос и не выдаёт награды повторно. Публичный рейтинг — по выбору учителя; по умолчанию личный результат и общий успех класса.

## 6. Учебная аналитика

Сохранять вопросы, попытки, итог, подсказки и понятные причины ошибок там, где тренажёр их действительно определяет. Показывать учителю индивидуальные и общеклассные результаты, число отвечавших и число учеников с трудностями по каждой теме. Различать первую ошибку и итоговое освоение. Не выдавать предположения за диагноз. Результаты отдельных учеников доступны только учителю и самому ученику.

## 7. Расширение

После обратной связи по пилоту — темы 3 класса, затем 4 класса; после проверки нагрузки, сохранения прогресса и учительского сценария — остальные курсы. Общую игровую карту и комнату сохраняем. Режим самостоятельного изучения остаётся доступным.
