# Курс Arduino: перенос в CyberLearn

## Результат

В выборе кампании появился курс **«Arduino: живая электроника»**: 11 уроков, четыре раздела. Внутри открывается локальная русская адаптация опубликованной лаборатории https://learn-arduino-red.vercel.app/ с исходными 3D-моделями, подключениями, примерами кода, настройками компонентов, звуком, камерой, миникартой, подсветкой строк и симуляциями.

Уроки: плата, мигание светодиода, кнопка, потенциометр, RGB, фоторезистор, HC-SR04, пьезоизлучатель, мотор, сервопривод, парковочный датчик.

После успешного запуска модели урок сохраняется через обычный `completeTask` CyberLearn. Повторный запуск не начисляет награды повторно. Для первых десяти уроков — 40 XP и 15 монет; итоговый проект — 100 XP и 35 монет. За весь курс — 500 XP, 185 монет и достижение «Инженер Arduino». Это правило прохождения исходного приложения: запуск готовой параметрической симуляции, а не проверка сборки на реальном оборудовании или компиляция произвольного C++.

558 переводов покрывают учебные объяснения, подключения, вкладки, выноски, инспектор, настройки и основные сообщения. Названия Arduino API, выводов и исходный синтаксис программ сохранены. Техническая маркировка самой платы остаётся исходной.

На телефоне после запуска показывается 3D-сцена. Остальные панели доступны прокруткой. CSS лаборатории изолирован в отдельном документе. Настройки и значения компонентов хранятся отдельно для каждого ученика; отметки о прохождении синхронизируются из школьного аккаунта. Ошибку сохранения можно повторить. Старый сброс локальных отметок скрыт, поскольку он не должен противоречить аккаунту.

## Происхождение

Автор, указанный в опубликованной странице: [Dilum Sanjaya](https://x.com/DilumSanjaya). Исходный сайт: https://learn-arduino-red.vercel.app/.

Поиск точного адреса сайта, одноимённых репозиториев и публичных проектов предполагаемого автора не подтвердил исходный GitHub или открытую лицензию на само приложение. Поэтому перенос оформлен как снимок опубликованной версии по прямому указанию пользователя, а не как подтверждённый open-source-проект. Авторство и исходные ссылки сохранены в документации и неизменном снимке. По последующему запросу пользователя внешние ссылки и водяной знак убраны из интерфейса. Нельзя объявлять авторский код MIT-лицензированным на основании лицензий зависимостей.

Оригинальные файлы и SHA-256: `third_party/learn-arduino/upstream/`, `snapshot.json`. Отдельно сохранены MIT-уведомление Three.js и OFL шрифтов Barlow/JetBrains Mono. Сборка не обращается к исходному сайту. `npm run art:arduino` воспроизводит локализованную копию из сохранённого снимка; обычная production-сборка делает то же автоматически.

## Поиск продолжения на GitHub

Проверено 22 октября 2026 года:

- [Sadeep78/learn-arduino-pro](https://github.com/Sadeep78/learn-arduino-pro): отдельный проект под [MIT](https://github.com/Sadeep78/learn-arduino-pro/blob/main/LICENSE). В `src/data/lessons.ts` **тоже 11 уроков**, а не дополнительная последовательность к оригиналу. Есть другие модели/инструменты, каталог компонентов, схемный редактор, AVR8js и список видеоглав. В проверенном API одна ветка `main`, форков нет. Связь с автором исходного сайта не подтверждена; не выдаём за официальное продолжение и не заменяем им перенесённую лабораторию. Заявления README о компиляции произвольного кода требуют отдельной проверки: `api/compile.ts` содержит заглушку с готовым HEX.
- [parkain707/learn-arduino-button-kr](https://github.com/parkain707/learn-arduino-button-kr): отдельная корейская переработка **одного урока про кнопку**; README прямо ссылается на исходный сайт. Дополнительных уроков ко всему курсу нет, открытая лицензия не найдена.
- [tahafarshbaf/arduino_course](https://github.com/tahafarshbaf/arduino_course): самостоятельный MIT-курс с более длинной последовательностью — C, электроника, кнопки/датчики, системы безопасности, уровень жидкости, скорость, драйвер мотора, DHT11, беспроводная связь, робот. Полезен как возможный источник тем/примеров для будущих собственных уроков, но не является продолжением моделей этого сайта. Материалы отсюда сейчас не импортировались.

Подтверждённого официального продолжения оригинальных 11 интерактивных сцен не найдено.

## Проверки

- `node scripts/arduinoSnapshot.check.mjs`: хеши снимка, неизменность GLSL и Arduino-кода при переводе.
- `node scripts/arduino.browser.check.mjs`: все 11 исходных симуляций при 1440/390 px, реальные пиксели WebGL, изменение параметров, русские вкладки, награды, отказ сети и повтор, повторный вход.
- `npx tsc --noEmit -p .`, `npm run validate:curriculum`, `node --import tsx scripts/pedagogy.check.ts`, `node --import tsx scripts/trainerConfig.check.ts`, `node --import tsx scripts/cosmetics.check.ts`.
- Production-сборка, серверный каталог и общие проверки навигации/раскладки запускаются отдельно после завершения браузерного прогона.

Фактический итог проверки: TypeScript, production-сборка, каталог 401 задания, методические проверки, 37 проверок конфигураций тренажёров, косметика и серверные тесты прошли. Браузер: 11 Arduino-сцен на двух ширинах, отдельная финальная проверка кириллицы и возврата к модели, семь кампаний, 19 существующих типов миссий, 84 активности на семи ширинах и шесть интерактивных сцен — без регрессий. Production-ресурсы лаборатории присутствуют; серверный каталог содержит все 11 Arduino-уроков. Снимки: `artifacts/arduino/`.

## Доработка вёрстки и оформления

Лаборатория приведена к тёмной палитре CyberLearn. Фиксированная масштабируемая раскладка заменена CSS-сеткой; 3D-сцена, чтение/код и лента уроков занимают отдельные области. Настройки компонента открываются в колонке материалов. Подписи включаются отдельно, запуск доступен рядом с камерой. Внешние ссылки и социальный водяной знак убраны с учебного экрана; авторство сохранено в документации. Исправлена локализация SVG-атрибутов (viewBox не переводится). На мобильных устройствах используется одна прокрутка, панель инструментов не закрепляется поверх уроков; уведомления и ошибка сохранения занимают собственные строки и не закрывают управление.

Проверка новой раскладки: все 11 симуляций на 1440/390 px, сохранение после ошибки сети, повтор без награды и повторное открытие курса прошли. TypeScript, production-сборка и проверка учебного каталога — без ошибок. Отдельный `scripts/arduinoLayout.browser.check.mjs` проверяет области, вкладки, разворачивание текста/кода, инспектор и обе кнопки запуска на 320, 390, 768, 1024, 1440 и 1920 px.

## Увеличение рабочей области

Боковая колонка сужена до 300–340 px, лента уроков уменьшена до 76 px (карточки 52 px вместо 78 px), панель камеры стала компактнее. На телефоне сцена занимает 70% высоты окна. Кнопка «На весь экран» разворачивает ту же WebGL-сцену на окно приложения, скрывая учебные панели и верхнее меню; кнопка «Свернуть» или Escape возвращает обычную раскладку. Эксперимент и canvas сохраняются, запуск и камера доступны в развёрнутом виде. Проверены обе раскладки на шести ширинах 320–1920 px и встроенный режим на 1440/390 px; TypeScript, сборка и контроль снимка проходят.
