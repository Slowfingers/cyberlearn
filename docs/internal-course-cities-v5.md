# Внутренние карты заданий v5

Шесть школьных городов 3–8 классов приведены к стилю общего плана v10: графитовые фасады, стеклянные лаборатории, тёплые окна, небольшие площади и ограниченная подсветка. У каждого курса своя архитектура: библиотека, научные лаборатории, творческие студии, инженерные мастерские, программирование и связь, вычислительные центры.

`CampaignCity` выбирает отдельный WebP курса. Для остальных курсов сохранён прежний fallback на город 3 класса, теперь в новой стилистике. Геометрия дороги, расположение миссий, пагинация и движение аватара сохранены.

Ассеты: `public/art/neo-academy/city-grade3-v5.webp` … `city-grade8-v5.webp`; исходники с теми же именами `.png` в `sources/`. Встроенный ImageGen, полные промпты и список файлов — `internal-course-cities-v5.json`.

Проверки: TypeScript, production build, curriculum, `check:campaign`. Изолированная браузерная проверка движения проверяет загрузку каждой иллюстрации, все районы шести школьных курсов на пяти ширинах, движение героя, закрытые задания и длинные модули. Скриншоты вариантов: `artifacts/campaign-traveler/course_grade*-v5.png`.
