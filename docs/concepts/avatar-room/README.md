# Комната аватара: выбор ракурса

Два визуальных концепта до начала реализации комнаты и отдельных спрайтов. Оба созданы встроенным image_gen. Общий интерьер и палитра CyberLearn, разные камеры. Персонаж на концептах иллюстративный; в игре его заменит надетый аватар ученика.

Изометрия: свободная расстановка мебели на полу, видимые габариты предметов и проходы. Фронтальный вид визуальной новеллы: более крупный персонаж и интерьер, предметы расставляются в заранее обозначенные позиции.

Общая идея следующего этапа: бесплатная стартовая комната, отдельный каталог мебели за заработанные монеты, предпросмотр покупки, размещение только купленных вещей, сохранение обстановки у ученика.
