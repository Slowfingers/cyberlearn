# Спокойный город и длинный маршрут

Фон сгенерирован встроенным image_gen, затем сохранён в проект. Исходник: `public/art/neo-academy/sources/city-v3.png`. Рабочий WebP: `public/art/neo-academy/city-v3.webp`.

Крупные здания по краям, открытая набережная, спокойные материалы и локальная подсветка заменяют плотную сетку фасадов. Номера миссий, статусы, линии и персонаж остаются HTML/SVG поверх изображения. На участке до десяти миссий; короткие районы тоже используют всю длину маршрута. Полная карта на узких экранах прокручивается по горизонтали, выбранная миссия центрируется. Существующие учебные миссии не добавлялись и не удалялись.
