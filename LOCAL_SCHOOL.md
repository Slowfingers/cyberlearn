# Работа без Firebase

По умолчанию приложение использует общий файловый сервер. Ученики входят по имени и коду класса; аккаунт с таким именем внутри класса создаётся при первом входе. В двух разных классах одинаковые имена — разные аккаунты. Код класса даёт доступ к ученику с указанным именем, поэтому это простой классный вход, а не персональная проверка личности.

Единственный преподаватель создаётся вне сайта:

```sh
npm run setup:teacher -- imyourteacher
```

Команда также позволяет сменить данные существующего преподавателя, сохранив его классы. Случайный пароль записывается в `.cyberlearn/teacher-access.txt`. Учителя через форму зарегистрировать нельзя.

Данные находятся в `.cyberlearn/data.json`, вне браузера и production-ассетов. Каталог исключён из Git и запрещён для выдачи сервером Vite. Пароль учителя хранится как PBKDF2-хеш с индивидуальной солью; файл доступа содержит сам пароль и доступен владельцу компьютера. Файл данных не зашифрован: защищён правами файловой системы. Резервируйте каталог `.cyberlearn` при выключенном сервере. Сессии сохраняются на сервере только в виде SHA-256-хешей случайных токенов и истекают через 12 часов. Смена пароля командой setup:teacher закрывает старые сессии. Cookie сессии HttpOnly/SameSite=Strict; HTTPS включает Secure.

Для запуска:

```sh
npm run build
npm start
```

Все устройства должны открывать один и тот же сервер. В локальной сети вместо `localhost` ученики используют IP компьютера преподавателя и порт 3000. Для работы из разных сетей нужен постоянно доступный сервер с HTTPS и постоянным диском. Просто загрузить папку `dist` на статический хостинг недостаточно. Текущий dev-сервер запущен только на 127.0.0.1 для тестирования.

Папки создаются в списке классов. Фильтр выбирает школу, поле «Папка класса» переносит выбранный класс. Новые классы создаются в выбранной папке. Запросы «Поднять руку» видны преподавателю из всех его классов, с названием класса и папки. Обновление каждые четыре секунды. Ученик может отменить запрос, преподаватель — отметить «Помог».

Прежние тестовые данные localStorage не удаляются, но не импортируются в серверную базу автоматически. Firebase можно явно включить через VITE_BACKEND=firebase; новый классный вход, папки и помощь реализованы для файлового сервера.

Проверка сервера: `npm run check:school` (отдельные сессии, запрет регистрации учителей, права, папки, помощь, хеширование).

## Контрольные

«Создать контрольную» открывает редактор работы для выбранного класса. До 30 вопросов: один правильный вариант из 2–6, открытый ответ, короткий ответ / минизадача. Укажите баллы, сохраните черновик или откройте работу классу. Короткие ответы сравниваются без учёта регистра и повторяющихся пробелов.

У учеников опубликованные работы появляются в разделе «Контрольные учителя» (обновление списка каждые 10 секунд). Правильные ответы не передаются браузеру ученика. После отправки ответы изменить нельзя. В кабинете учителя есть список ответов, ручные баллы и комментарии. Работу можно закрыть и снова открыть; вопросы после первой отправки заморожены, чтобы результаты оставались сопоставимыми. Новую попытку создайте отдельной контрольной. После закрытия приёма ученик, уже отправивший ответы, продолжает видеть свою работу и комментарии.

Минизадание с маршрутом робота доступно из редактора отдельной кнопкой. Оно использует прежний конструктор карты и автоматическую проверку.
