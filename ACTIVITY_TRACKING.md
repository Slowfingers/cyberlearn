# Система отслеживания активности студентов

## Обзор

Система автоматически отслеживает активность студентов при выполнении заданий для выявления потенциального списывания.

## Отслеживаемые метрики

### 1. **Переключения вкладок** (`totalTabSwitches`)
- Автоматически фиксируется каждый раз, когда студент покидает вкладку с заданием
- Использует `visibilitychange` API браузера
- **Пороги:**
  - 🟢 0-10: Нормально
  - 🟡 11-20: Средняя активность
  - 🔴 >20: Высокая активность (подозрительно)

### 2. **Количество ошибок** (`totalErrors`)
- Подсчитывается при каждой неудачной попытке выполнения задания
- Сохраняется для каждой попытки отдельно

### 3. **Подозрительные задания** (`suspiciousTaskCount`)
- Задание считается подозрительным, если:
  - Более 10 ошибок в одной попытке, ИЛИ
  - Более 5 переключений вкладок в одной попытке

### 4. **Средние ошибки на задание** (`avgErrorsPerTask`)
- Рассчитывается как среднее количество ошибок по всем попыткам

### 5. **История попыток** (`recentAttempts`)
- Сохраняются последние 50 попыток (показываются последние 10)
- Для каждой попытки:
  - ID задания
  - Количество ошибок
  - Количество переключений вкладок
  - Время выполнения (в секундах)
  - Результат (успех/неудача)
  - Временная метка

## Как это работает

### Автоматическое отслеживание

1. **При открытии задания:**
   - Вызывается `startTaskAttempt(taskId)`
   - Начинается отслеживание переключений вкладок

2. **При каждой ошибке:**
   - Вызывается `recordError()`
   - Счетчик ошибок увеличивается

3. **При завершении задания:**
   - Вызывается `endTaskAttempt(userId, success)`
   - Данные сохраняются в Firebase
   - Обновляются метрики подозрительной активности

### Хранение данных

Данные хранятся в Firebase в профиле пользователя:

```typescript
{
  taskAttempts: [
    {
      taskId: "lua_034",
      timestamp: "2026-04-17T12:00:00Z",
      errors: 3,
      tabSwitches: 2,
      duration: 120,
      success: true
    }
  ],
  suspiciousActivity: {
    totalTabSwitches: 15,
    highErrorTasks: ["lua_034"]
  }
}
```

## Интерфейс учителя

### Таблица студентов

Добавлены новые колонки:
- **Вкладки**: Общее количество переключений (цветовая индикация)
- **Подозр.**: Количество подозрительных заданий (с иконкой предупреждения)

### Детальная информация о студенте

При клике на студента открывается модальное окно с:

1. **Мониторинг активности:**
   - Общее количество переключений вкладок
   - Количество подозрительных заданий
   - Среднее количество ошибок на задание
   - Предупреждение при высокой активности

2. **Последние попытки:**
   - Список последних 10 попыток
   - Детали каждой попытки (ошибки, вкладки, время)
   - Цветовая индикация подозрительных значений

## Интерпретация данных

### 🟢 Нормальная активность
- Переключений: 0-10
- Ошибок: 0-5 на задание
- Подозрительных заданий: 0

### 🟡 Средняя активность
- Переключений: 11-20
- Ошибок: 6-10 на задание
- Требует внимания

### 🔴 Подозрительная активность
- Переключений: >20
- Ошибок: >10 на задание
- Переключений в одной попытке: >5
- **Рекомендация:** Провести беседу со студентом

## Конфиденциальность

- Данные доступны только учителю класса
- Не отображаются другим студентам
- Используются только для образовательных целей
- Автоматическое удаление старых попыток (хранятся последние 50)

## Технические детали

### Файлы
- `utils/activityTracker.ts` - Основная логика отслеживания
- `types.ts` - Интерфейсы `TaskAttempt`, расширенные `User` и `StudentProgress`
- `services/mockBackend.ts` - Расчет метрик в `getClassStudents()`
- `components/StudentDashboard.tsx` - Интеграция отслеживания
- `components/TeacherDashboard.tsx` - Отображение данных

### API браузера
- `document.addEventListener('visibilitychange')` - Отслеживание переключений вкладок
- Автоматическая очистка при размонтировании компонента

## Ограничения

- Не отслеживает активность вне браузера
- Переключение между окнами браузера также считается
- Требует JavaScript и современный браузер
- Данные локальны для каждого устройства (синхронизируются через Firebase)
