# Отслеживание активности

При входе ученика приложение слушает `visibilitychange` и `blur`. События в пределах 400 мс объединяются, чтобы одно переключение окна не учитывалось дважды. Счётчик отправляется через callable API с задержкой 600 мс; после ошибки сохранения повторяется через 5 секунд, пока тот же пользователь остаётся в сессии.

Попытки автоматически отслеживаются для `grid`, `html`, `terminal` и `quiz`. При начале сохраняются ID задания и время; при завершении — ошибки, переключения окна, длительность и результат. Сервер добавляет временную метку и сохраняет последние 50 попыток, кабинет учителя показывает последние 10. Для остальных тренажёров пока фиксируется выполнение, но не подробная история попыток.

Завершённая попытка отделяется от текущей до сетевого запроса: поздний ответ сервера не стирает следующую попытку. Сервер обновляет историю и счётчики транзакциями, не заменяя профиль устаревшей копией. Учитель получает данные только учеников своего класса; прямое чтение базы браузером запрещено.

Переключение окна само по себе не доказывает списывание. Счётчик включает переходы в другие приложения и может срабатывать при работе с учебными материалами. Цветовые пороги в кабинете — подсказка для обсуждения, а не автоматический вывод о нарушении. События при закрытии браузера отправляются по возможности и могут потеряться: гарантированной доставки во время выгрузки страницы нет.
