# Illustrated CyberLearn game UI

Generated with the built-in image_gen tool. Original RGBA PNGs are retained; lossless WebP copies are used by the site. Decoded WebP pixels are verified equal to the PNGs. No artwork was modified during conversion.

Nine-slice borders preserve painted corners and edge details. Button labels remain live HTML for readability and accessibility. The shared integration is at the end of `index.css`.
