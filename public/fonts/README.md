Rajdhani Regular, SemiBold and Bold come from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/rajdhani

Licensed under SIL OFL 1.1; see Rajdhani-OFL.txt.
These WOFF2 files retain the original outlines. Glyph bounding boxes were
recalculated using fontTools 4.66.1 (`TTFont(..., recalcBBoxes=True)`,
`glyph.recalcBounds(font['glyf'])`, `font.flavor = 'woff2'`) to remove Firefox
sanitizer warnings. Nonempty glyph bounds were checked again after saving.
