# Методическая структура курсов 3–7 классов

Ученик проходит один учебный цикл: главная идея → разобранный пример → самостоятельная попытка → проверка результата → вопрос для объяснения своими словами. В основной карточке нет списка стандартов, технических рекламных обещаний и вымышленных сюжетных этапов. План действий и справочник команд открываются по запросу. Озвучивание включается самим учеником.

## Маршрут

| Класс | Разделы | Задания | Основной переход |
| --- | ---: | ---: | --- |
| 3 | 7 | 70 | От знакомых предметов и действий к файлам, командам, данным и безопасному общению |
| 4 | 7 | 70 | От команд к повторениям, сравнениям, условиям и проверке результата |
| 5 | 7 | 70 | От отдельного действия к функции, данным, способам поиска и ограничениям моделей |
| 6 | 8 | 40 | От управления файлами к формулам, алгоритмам, первым программам и версиям проекта |
| 7 | 9 | 70 | От первых программ Python к циклам, данным, страницам и проверке решений |

Разделы сгруппированы по учебному действию. В меню раскрыт текущий раздел; остальные можно открыть самостоятельно. Названия проверочных заданий обозначают конкретное понимание, например «Считаем биты в байтах», а не «Экзамен по всей архитектуре компьютера».

## Объяснение и практика

- У понятия есть короткое объяснение, другой разобранный пример и вопрос для переноса. Пример не является готовой программой текущего упражнения.
- Для программирования используются самостоятельные заготовки: пустой маршрут, каркас HTML, программы с обозначенным местом для дополнения или поле команд. Эталонный `initialCode` сохранён отдельно для проверки. В уроке поиска ошибки оставлен ошибочный маршрут, который нужно исправить.
- Цель описывает действительную возможность тренажёра. Маршрут по клеткам не называется полноценным платформером; сумма — построением диаграммы; кнопка HTML — разработкой интерактивного счётчика.
- Таблица использует данные своего задания. Умножение, сумма и условие IF различаются. Тексты результатов и граница IF берутся из условия, включая проверку значения ровно на границе.
- Вопросы не требуют термина, которого нет в объяснении. Например, вместо названия алгоритма графов ученик сравнивает суммы задержек двух путей; вместо обозначения сложности словаря читает значение по ключу.
- Ошибка сопровождается разбором. После успеха предлагается объяснить принцип, а не только перейти за следующей наградой.

## Поддержка содержания

`curriculum/pedagogy.ts` содержит короткие авторские карточки, связи понятий с ID, разделы, реальные цели тренажёров и самостоятельные заготовки. `curriculum/quizTitles.ts` содержит отдельную цель каждого проверочного задания. `constants.ts` применяет этот слой после конфигов тренажёров. Исходные файлы модулей сохраняют данные, проверочные вопросы и эталоны; их старые длинные HTML-рассказы не показываются ученику — экспортируемая теория заменяется короткой карточкой.

Все 320 ID сохранены. Пройденные задания, опыт, покупки и награды не обнуляются. Число разделов вычисляется по фактическому маршруту.

Проверки: `npm run check`, `npm run build`, `npm run check:browser`. Проверяются полнота карточек, объём основного текста, стабильность связей по ID, наличие самостоятельных заготовок, соответствие диапазонов таблиц и реальных алгоритмов. Браузерная проверка дополнительно проверяет мобильное объяснение и все 13 табличных заданий с верными и неверными формулами.

Педагогический эффект следует оценивать наблюдением: может ли ребёнок пересказать идею, начать практику без объяснения взрослого, объяснить ошибку и применить принцип в другой ситуации. Автоматические проверки подтверждают работу приложения и целостность программы, но не заменяют такую апробацию.

## Визуальная мастерская

Набор текста: единая строка образца и ввода по принципу Stamina Online. Нативный textarea расположен поверх цветного текста, без отдельного видимого инпута. Набранные символы, ошибки и курсор видны на месте. Компактный прогресс, скрываемая клавиатура, переключение РУС/ENG и Shift. Ошибку можно исправить; скорость не давит на ребёнка. Для программ с несколькими строками доступен Enter.

Сортировка файлов — «Бюро цифровых посылок»: оригинальные SVG-файлы и папки, перетаскивание мышью/пальцем или выбор «файл → папка». Ответ не раскрывается заранее. Краткая памятка по запросу; после ошибки даётся объяснение. Подозрительные программы попадают в карантин по контексту, а не только по расширению.

Конструктор — «Студия игровых экранов»: детали и области телефона. Неверное размещение не засчитывается; детали можно заменить или убрать. Количество областей соответствует конфигурации урока.

«Школа робота» использует названия и примеры конкретного урока. Карточку можно вернуть из набора и исправить разметку. Итог говорит о подготовке данных, а не обещает безошибочный ИИ.

Ассеты в `WorkshopArt.tsx` нарисованы в SVG; внешние изображения не нужны. Остальные симуляторы используют общую спокойную палитру панелей и кнопок. Двоичные лампы получили собственные SVG-состояния. Поведение и семантические цвета существующих схем сохранены. Системная настройка уменьшения движения учитывается.

`npm run check:workshop` проверяет ввод с Shift, кириллицу и переносы строк, исправление ошибок, реальное перетаскивание файлов, конфигурацию конструктора, возврат карточек ИИ, однократное завершение и ширину мобильных экранов. Скриншоты сохраняются в `/private/tmp/cyberlearn-*.png`.


Объяснение с наставником: 320 уроков используют последовательность «Объяснение → Пример → Вопрос → Практика». Объяснение раскрывается короткими частями; дублирующая кнопка отдельного примера удалена. Вопрос имеет три варианта и объяснение каждого выбора. Ошибку можно исправить; обычный переход к практике открывается после верного ответа. Для повторного прохождения оставлен явный переход «Уже знаю тему». Ответ наставнику не начисляет награды за самостоятельную практику.

Понятия, разобранные примеры и вопросы сверены с условиями задач. Отдельные карточки добавлены для NAND, учебного нейрона, фильтрации Python, запуска файла, CSV, статистики, ping, вычислений JavaScript, сортировки SQL и создания таблицы. Исправлена связка теории с маршрутом робота g5_l49 и проверка кнопки g7_l34. Пример CSS меняет цвет, а не HTML-тег. Каркас экрана, отклик игры, сквозное шифрование и проверка ответов ИИ получили собственные объяснения.

`scripts/mentorActivities.check.ts` проверяет наличие понятного объяснения и вопроса для каждого урока, три разных варианта, обратную связь и рендер всех 320 объяснений. В браузере дополнительно проверены ошибка, повторный выбор и открытие практики.
