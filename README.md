# CyberLearn

Учебная платформа для 3–8 классов: 390 уроков, кабинеты ученика и учителя, контрольные, папки классов, поднятая рука и игровой прогресс.

## Локальная работа

Нужен Node.js 22. Установка и запуск:

```sh
npm ci
npm run setup:teacher -- imyourteacher
npm run dev
```

Страница: `http://127.0.0.1:3000/`. Данные хранятся на сервере в приватной папке `.cyberlearn`, а не в localStorage браузера. Учитель один: логин и случайный пароль создаются командой настройки; файл доступа находится в `.cyberlearn/teacher-access.txt`. Повторная настройка может заменить пароль и завершает сессии — не запускайте её без необходимости. Ученики входят по имени и коду класса. Учитель создаёт произвольно названные папки и распределяет классы по ним.

Для production на собственном сервере с постоянным диском:

```sh
npm run build
npm start
```

Приватные файлы и сервисные ключи не публикуются. Для HTTPS используйте обратный прокси.

## Публикация на Vercel

Статического `dist` недостаточно для входа. Добавлен маршрут `api/local.ts`, который сохраняет серверные данные в существующем Firebase. Настройка серверного доступа и ограничения переноса старых данных описаны в [docs/vercel.md](docs/vercel.md). Без серверных переменных и закрытых правил вход в опубликованной версии пока не заработает.

## Курс 8 класса

70 тем из предоставленной программы сохранены в исходном порядке и объединены в 14 разделов. Каждый урок содержит объяснение, отдельный пример, вопрос наставника с обратной связью и самостоятельную практику. [Карта курса и методические ограничения](docs/grade8.md).

Python исполняется в отдельном Worker через Pyodide; SQL — в SQLite с учебными таблицами. Загрузка среды требует доступа к CDN. Загрузка ограничена 60 секундами, исполнение — 5 секундами. Уроки 8 класса дополнительно проверяют контракты функций на других входных данных. HTML/CSS/JS-практика содержит работающий предпросмотр и проверку обработчика кнопки. Сетевые, IoT и серверные сценарии явно учебные; реальные устройства и чужие системы не используются.

## Проверки

```sh
npm run check
npm run check:grade8
npm run check:cloud
npm run check:school
npm run build
```

`check:grade8` дополнительно требует Python 3: выполняет все эталонные Python/SQL-программы, проверяет 70 ID и порядок уроков, отклоняет незаполненные шаблоны и печать ответа без реализации функции. `check` проверяет типы, методические карточки, каталог, косметику, начисления, серверные права и регрессии. Серверные проверки используют тестовое хранилище и не заменяют проверку опубликованного проекта.
